# Unified Mentor Internship Projects    
### Organization: Unified Mentor  
### Intern: Nihal Thakare  

This repository contains the three major data-driven projects completed during my internship at **Unified Mentor**. The projects span machine learning, deep learning, and business intelligence, showcasing real-world applications in pricing, sales forecasting, and retail analytics.

---

## Project 1: TCS Stock Price Prediction Using LSTM  

**Objective**: Predict the future stock prices of Tata Consultancy Services using time-series deep learning.  

**Tools & Libraries**:  
- Python, NumPy, Pandas  
- Matplotlib, MinMaxScaler  
- TensorFlow/Keras – LSTM Layers  

**Highlights**:
- Data preprocessed with proper scaling and windowing
- Built and trained an LSTM model for trend capture
- Visualized predictions against actual values
- Evaluated using RMSE for model performance

**Outcome**:  
Model captured temporal trends and provided forward-looking predictions on stock movements.

## Project 2: Laptop Price Prediction Using Supervised Learning  

**Objective**: Predict the price of laptops based on specifications using regression algorithms.

**Tools & Libraries**:  
- Python, Pandas, NumPy, Matplotlib, Seaborn  
- Scikit-learn: Linear Regression, Ridge, Lasso  
- GridSearchCV for hyperparameter tuning

**Key Steps**:
- Extensive feature engineering from raw specs (CPU, RAM, Storage, Display, GPU)
- One-Hot Encoding for categorical attributes
- Model comparison using MSE and R²
- Coefficient interpretation for feature importance

**Outcome**:  
An interpretable regression model, useful for e-retail laptop price estimation engines.

## Project 3: Pizza Business Intelligence Dashboard (Power BI)  

**Objective**: Analyze year-long pizza sales to identify trends, peak performance windows, and top/least performing products.  

**Tool**: Power BI, Power Query, DAX 

**Key Dashboards**:
- Sales by Category and Size
- Daily & Hourly Order Trends
- Top and Bottom Performing Pizzas (By Revenue & Volume)
- Monthly Revenue & Forecast
- Peak Hours and Day-wise Order Distributions

**Insights**:
- **Classic Deluxe Pizza** – most ordered
- **Thai Chicken Pizza** – most profitable
- Highest sales on **Fridays and Saturdays**, peak hours: **12–1 PM**

**Outcome**:  
Business insights that can inform product strategy, staffing, and marketing in F&B sector.
